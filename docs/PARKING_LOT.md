# Parking lot

Ideas, tangents and defects noticed while doing something else. They go here so the current task stays on course and nothing is lost when a session ends. `/orchestrate` and `/brainstorm` read this at the start of each phase.

An entry moves down the page: Open, then Adopted (with the spec that took it) or Dropped (with the reason). Entries are not deleted.

Format: `- YYYY-MM-DD: <what>. Noticed during <task>. <why it matters, one line>.`
